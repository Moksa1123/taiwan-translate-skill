## 快速參考

### 智能工具

```bash
# 搜尋詞彙
python scripts/search.py <關鍵字>

# 翻譯文字
python scripts/translate.py "<英文文字>"

# 翻譯 PO 檔案
python scripts/translate.py --po <檔案路徑>
```
