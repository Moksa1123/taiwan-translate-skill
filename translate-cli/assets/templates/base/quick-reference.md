## 快速參考

### 智能工具

```bash
# 搜尋詞彙
python scripts/search.py <關鍵字>

# 詞彙查詢（列出命中詞彙，不代換整句）
python scripts/lookup.py "<英文文字>"

# 抽出 PO 未翻譯項目 / 翻譯把關
python scripts/po.py extract  <檔案路徑>
python scripts/po.py validate <檔案路徑>
```

| English | 台灣正體中文 |
